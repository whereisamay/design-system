# Button

The pill button: the main call to action on every page.

**Markup:** `<a class="btn btn-primary">` or `<a class="btn btn-ghost">`; add `btn-sm` for the compact size. Works on `<button>` too.

- **Primary** (`ink` fill, `cream` text) is the one thing you most want clicked. One per view.
- **Ghost** (transparent, `ink` border) sits next to a primary as the second choice.
- **Small** (`btn-sm`, 10px × 18px, 14px) for inline actions inside cards and case-study footers.
- Both lift 2px up-left on hover; the primary turns `coral`. The `cream` label on `coral` reads 3.0:1, below 4.5:1 for 15px text (kept from the source, flagged).
- Labels: short, sentence case, verb first ("Read my work", "Get in touch"). An arrow ↗ marks a link that leaves the site.

**Don't** put two primaries side by side, or use a square-cornered button.
