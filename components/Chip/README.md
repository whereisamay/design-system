# Chip

A small uppercase pill that names a category: Essay, Travel, Fintech.

**Markup:** `<span class="chip">Essay</span>`; `chip chip-outline` for the quieter outlined version.

- `label-chip` type (12px, 700, 0.04em, uppercase) in `ink` on `mustard-2` (10.6:1).
- One chip per card, above the title. Keep it to one or two words.
