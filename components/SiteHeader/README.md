# SiteHeader

The sticky top bar: wordmark left, section links centre, social icons right.

**Markup:** `<header class="site-header"><div class="header-inner">` with `.logo` (+ `.logo-dot`), `.main-nav` links and `.icon-btn`s.

- 78px tall, `cream` at 82% opacity with a 10px backdrop blur and a `line-soft` bottom rule.
- The wordmark is the name in `wordmark` type plus a `coral` full stop. There is no logo file.
- Nav links are `label-nav`; a `coral` underline sweeps in from the left on hover.
- Under 760px the nav and icons collapse behind a three-line toggle (the consumer provides it).
