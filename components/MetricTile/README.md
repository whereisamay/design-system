# MetricTile

A bordered box with one headline number and a short label: the impact row on a case study.

**Markup:** `<div class="metric"><b>40–45</b><span>weekly support queries removed</span></div>`.

- Number in Fraunces 600, 30px, tabular figures. Label in `ink-soft`, 13.5px.
- Use them in rows of three. Only real, sourced numbers: never filler stats.
