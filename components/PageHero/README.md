# PageHero

The opener for an article or case-study page.

**Markup:** `<section class="page-hero">` with `.back-link`, an `.eyebrow`, `.page-title`, `.page-sub` and optional `.page-meta`.

- `cream-2` band with a `mustard-2` glow in the top-right corner.
- The back link always comes first and says where it goes ("← Back to the portfolio").
- Title in `display-page`; subtitle in `ink-soft`, one sentence.
