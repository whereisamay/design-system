# DataTable

A rounded, ink-bordered table for short reference lists inside articles.

**Markup:** `<div class="table-scroll"><table class="menu-table">`.

- The header row is `mustard-2` with Fraunces 600. Rows are split by `line` rules, and the first column has a rule on its right.
- Links inside use an `ink` underline in `coral`.
- Under 640px, the writer site swaps the table for a `mustard-2` select dropdown. The consumer provides it.
