# SectionHeading

The three-part opener every section uses: eyebrow, title, subtitle.

**Markup:** `<p class="eyebrow">` + `<h2 class="section-title">` + `<p class="section-sub">`.

- **Eyebrow:** `label-eyebrow` in `coral`, written in lowercase in the markup and set uppercase by CSS. It's playful and short ("the backstory", "WAQs").
- **Title:** `display-section` in Fraunces 600. Two to four words.
- **Subtitle:** `text-lede` in `ink-soft`, one or two sentences, max 620px wide.
- The 13px `coral` eyebrow reads 3.0:1 on `cream`. That's below 4.5:1, so it's kept exact from the source and flagged; never use `coral` for smaller or lighter text.
