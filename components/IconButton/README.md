# IconButton

A 38px round outlined button for social links in the header.

**Markup:** `<a class="icon-btn" aria-label="…">` wrapping an 18px inline SVG that uses `fill="currentColor"`.

- Border `border-icon` (1.5px) in `ink`. On hover it fills `ink`, the icon turns `cream`, and it tilts −8°.
- Always give it an `aria-label`: there is no visible text.
- Icons are simple filled brand glyphs (LinkedIn, Instagram). No icon font.
