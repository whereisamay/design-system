# ChatBubble

Speech bubbles for showing a conversation with an AI agent.

**Markup:** `<div class="chat">` with `.bubble.q` (the person, right-aligned, `ink` fill) and `.bubble.a` (the agent, left-aligned, `cream` fill).

- The frame sits on `sage` with a 2px `ink` border and `radius-lg`.
- Label any made-up example as dummy data underneath.
