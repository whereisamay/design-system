# SiteFooter

The dark sign-off at the bottom of every page.

**Markup:** `<footer class="site-footer">` with `.footer-title`, `.footer-grid` (email + `.footer-socials`) and `.footer-bottom`.

- The only `ink` surface in the system. Text is `cream` (16:1); small print uses `on-ink-muted`, the divider `on-ink-line`.
- A soft `coral` glow sits in the bottom-left corner.
- The title is a warm invitation in two lines ("Let's write something together.", "Let's build something together.").
