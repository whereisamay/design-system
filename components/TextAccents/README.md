# TextAccents

Two ways to make one word in a big serif headline sing.

- **Script** (`<span class="script">`): italic Fraunces 500 in `coral`. Use it for a name, at display sizes only (24px+).
- **Highlight** (`<span class="highlight">`): italic, with a `mustard-2` marker stroke drawn under the lower third, tilted −1°.
- At most one of each per headline. Never on body text.
