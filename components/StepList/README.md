# StepList

A numbered sequence with big italic `coral` numerals.

**Markup:** `<ol class="step-list">` with `<li>`s. Use `step-list plain` inside article text for an unboxed version (18px, 1.75 leading).

- Boxed by default (2px `ink` border, `radius-md`) for how-it-works flows in case studies.
- Numerals are Fraunces italic 700, 28px. They're large text, so `coral` passes at 3:1.
- Start each step with a bold short phrase.
