# TextLink

A bold inline link with a 2px `coral` underline, used for "Read it →".

**Markup:** `<a class="ds-link">` (or `work-card-link` inside a WorkCard, where it sticks to the card's bottom).

- 14px, weight 700, `ink` text. The `coral` underline is a mark, not text, so it only needs 3:1 (it gets 3.0:1 on `cream`).
- End with → for "go deeper on this site" and ↗ for "leave the site".
