# BlobPortrait

The hero headshot inside an organic blob: the most recognisable shape in the system.

**Markup:** `.blob-portrait` > `.photo-blob` + `.photo-frame` > `img`, plus a `.sticker-dots` sticker.

- A `mustard` blob behind a 6px `ink`-framed photo cut to the same blob shape. The blob slowly morphs over 12s and stops when the viewer prefers reduced motion.
- A small dot-grid sticker overlaps the top-left.
- Use the `headshot.png` asset. One per site, in the home hero only.
